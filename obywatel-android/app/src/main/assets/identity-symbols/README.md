# Pakiet podstawowych flag SVG

50 plików SVG z projektu [lipis/flag-icons](https://github.com/lipis/flag-icons), katalog `flags/4x3`.

Nazwy plików zachowują kody ISO 3166-1 alpha-2. Licencja projektu: MIT; pełny tekst w `FLAG-ICONS-LICENSE.txt`.

Pakiet służy do wyświetlania flag jako znaków identyfikacyjnych. Nie oznacza automatycznego uprawnienia do używania herbów, godeł, pieczęci ani logotypów, ani do sugerowania oficjalnego poparcia przez państwo lub organizację. Należy respektować przepisy krajowe dotyczące flag.

Kody: pl, us, gb, de, fr, it, es, ua, ru, cn, jp, in, br, ca, au, ch, at, be, nl, se, no, dk, fi, ie, pt, gr, cz, sk, hu, ro, bg, hr, si, lt, lv, ee, tr, il, ps, sa, ae, eg, za, ng, ke, mx, ar, kr, id, nz.
